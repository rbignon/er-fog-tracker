Fog Gate Randomizer Tracker

Visualize, track, and share your Fog Gate Randomizer exploration progress with your stream audience in real-time.

The Fog Gate Randomizer is a mod for Elden Ring that randomizes where each fog gate leads. Instead of predictable connections, every fog gate becomes a mystery — stepping through might take you to a late-game area, a boss arena, or somewhere completely unexpected.

This transforms Elden Ring into a roguelike exploration experience where you must carefully navigate the world, discover new paths, and adapt your route based on what you find.

What does this tracker do?

The Fog Gate Randomizer Tracker helps you keep track of your discoveries:

  • Interactive graph — Visualize all zones and their connections as you discover them
  • In-game overlay — See your current zone and available exits without leaving the game
  • Automatic tracking — The mod detects fog gate traversals and updates the graph in real-time
  • Exploration mode — Undiscovered connections show as "???" to avoid spoilers
  • Stream integration — Share your progress with viewers via an OBS overlay or interactive link

1. Installation

Download the launcher

Download the latest release from GitHub:

Download for Windows

Extract and launch

  1. Extract the ZIP archive to a folder of your choice
  2. Run FogRandoTracker.exe

2. Launcher Configuration

Connect to the server

In the launcher, enter your credentials from the dashboard:

  • Server URL — Copy from the dashboard's "Automatic Tracking" section
  • Token — Your personal authentication token (keep it secret!)

Click Connect to verify the connection.

Create a new game

Click Create New Game and select your Fog Gate Randomizer folder. The launcher will parse the randomizer files to set up accurate initial tracking.

💡 Creating the game from the launcher is recommended for more accurate automatic tracking.

Select a game and connect

Select your game from the list, then click Inject to start tracking. The launcher will wait for Elden Ring to start and inject the mod automatically.

3. Playing with the Mod

Launch the game

  1. Select your game in the launcher
  2. Click Inject
  3. The launcher will wait for Elden Ring to start
  4. Launch Elden Ring through the Fog Gate Randomizer
  5. The mod injects automatically once the game is detected

The in-game overlay

Once injected, an overlay appears in the top-right corner showing:

  • Current zone — Where you are right now (with connection status dot)
  • Progress counter — Discovered links / Total links, and in-game time
  • Great Runes — Icons showing which Great Runes you've collected
  • Stats — Death count
  • Zone exits — List of fog gates with their destinations (discovered in color, undiscovered as ???)

Keyboard shortcuts

F9 Toggle overlay visibility
F10 Toggle exits list (fold/unfold)
Shift+F10 Show only undiscovered exits

Auto-detection

When you traverse a fog gate, the mod automatically detects the transition and updates your progress:

  1. Entry detection — The mod monitors the game for teleport animations (fog walls, waygates, sending gates, etc.) and records your position when one starts
  2. Exit detection — After the loading screen, the mod captures your new position
  3. Server resolution — The entry and exit positions are sent to the server, which identifies the zones and marks the link as discovered

The detection works for most fog gate types: randomized fog walls, waygates, sending gates, coffin rides, boss teleports, etc.

⚠️ Auto-detection is not 100% reliable. Some transitions may fail to be detected due to unknown animations, ambiguous positions, or edge cases. If a discovery is missed, you can manually mark zones as discovered on the web graph.

The web graph

Open your game on the dashboard to see the interactive graph:

  • The graph updates automatically when you traverse a fog gate
  • Your current zone is highlighted
  • Click on zones to see their connections and add tags
  • Use the search bar to find specific zones
  • Toggle "Frontier" to highlight zones with undiscovered exits

4. Sharing with Viewers

Viewer link (interactive)

Share a link with your chat or Discord for read-only viewing:

  1. Open your game on the dashboard
  2. Click the Stream button
  3. Copy the Viewer Link

Viewers can navigate the graph freely, zoom, search, and click on zones — but they can't modify anything.

OBS overlay (stream)

Add the graph as an overlay on your stream:

  1. Click the Stream button
  2. Configure the counter position and size
  3. Copy the OBS Overlay URL
  4. In OBS, add a new Browser source
  5. Paste the URL and set dimensions to 1920 x 1080

The overlay has a transparent background and syncs with your view — when you select a zone or use frontier mode, viewers see the same thing.

5. Customizing the Overlay

Configuration file location

Create a file named fog_rando_tracker.toml in the same folder as the DLL (your Fog Gate Randomizer folder).

Font and colors

[overlay]
# Font settings
font_path = ""                    # Path to TTF font (empty = system default)
font_size = 16.0                  # 16 for 1080p, 24 for 4K
icon_size = 16.0                  # Icon size (optional, defaults to font_size)

# Colors (hex format)
background_color = "#141414"
background_opacity = 0.7          # 0.0 = transparent, 1.0 = opaque
text_color = "#FFFFFF"
text_disabled_color = "#808080"
discovered_color = "#80FF80"      # Green for discovered exits
undiscovered_color = "#B3B3B3"    # Gray for ??? exits

# Border
show_border = false
border_color = "#404040"

# Text shown when zone is unknown
zone_unknown_text = "(traverse a fog to identify)"

Overlay size and position

[overlay]
# Position relative to the top-right corner (in pixels)
position_offset_x = 20.0    # Margin from the right edge
position_offset_y = 20.0    # Margin from the top edge

# Maximum overlay height in pixels (optional)
# If exceeded, exits font is scaled down, then truncated with "+ X others"
max_height = 300.0

# Minimum font scale for exits (0.0 to 1.0, default 0.5)
# Below this, exits are truncated instead of scaled further
exits_min_font_scale = 0.5

Status line template

Customize what's shown in the overlay header:

Text variables

{zone} Current zone name
{discovered} Number of discovered links
{total} Total number of random links
{progress} Progress percentage (0-100)
{status} Connection status indicator (●)
{map} Current map ID (e.g., m60_44_36_00)
{deaths} Total death count
{igt} In-game time (H:MM:SS)
{runes} Number of Great Runes (0-7)
{kindling} Number of Messmer's Kindling (DLC)
{scaling} Zone scaling info

Icon variables

{rune_icons} Great Runes as icons (filled/empty)
{kindling_icon} Kindling icon (DLC)
{death_icon} Death icon (skull)

Colors

Add a color to any variable with {variable:color}:

Named red, green, blue, yellow, orange, cyan, magenta, gray, white
Config discovered, undiscovered, disabled
Hex #RRGGBB (e.g., #FF0000)

Layout markers

$n New line
$> Right-align the rest of the line

Examples

# Default: zone on the left, status and progress on the right
status_template = "{zone}$>{status} {discovered}/{total}"

# With percentage
status_template = "{zone}$>{status} {progress}%"

# Two lines: zone + status, then runes and progress
status_template = "{zone}$>{status}$n{rune_icons}$>{discovered}/{total}"

# Speedrun style with IGT and deaths
status_template = "{zone}$>{status}$n{igt} | {death_icon}{deaths}$>{discovered}/{total}"

# Colored progress
status_template = "{zone}$>{status} {discovered:green}/{total}"

# DLC with kindling
status_template = "{zone}$>{status}$n{rune_icons} {kindling_icon}{kindling}$>{discovered}/{total}"

Keyboard shortcuts

[keybindings]
toggle_ui = "f9"                      # Show/hide overlay
toggle_exits = "f10"                  # Fold/unfold exits list
toggle_undiscovered_only = "shift+f10"  # Show only undiscovered exits
toggle_debug = "ctrl+f11"             # Show debug info (map_id, etc.)
upload_logs = "ctrl+f12"              # Upload logs for debugging

Keys support modifiers: ctrl+, shift+, alt+

6. FAQ

▶ The mod doesn't inject / overlay doesn't appear

Make sure you:

  • Run the launcher before starting Elden Ring
  • Don't have other overlay software conflicting (Discord overlay, etc.)
  • Have the DLL in your Fog Gate Randomizer folder

Try running the launcher as administrator if the issue persists.

▶ The overlay shows "???" for zones I've already visited

The mod only tracks fog gate traversals it observes directly. If you visited a zone before installing the mod, it won't know about it.

You can manually discover zones on the web graph by clicking on them and selecting "Mark as discovered".

▶ Zone detection is wrong or missing

Zone detection depends on the randomizer's spoiler log. If you created the game from the web instead of the launcher, some connections might be missing.

For best results, always create games from the launcher by selecting your Fog Gate Randomizer folder.

Note that zone detection is not 100% reliable — some edge cases may not be handled correctly. If you encounter a persistent detection issue, please open an issue on GitHub with details about the zone and how you reached it.

▶ Can I use this with other mods?

Yes! The tracker is designed to work alongside other mods. It uses the same injection method as other popular tools like Practice Tool.

If you're using Mod Engine 2, make sure the Fog Gate Randomizer is properly configured.

▶ The connection status shows red / disconnected

Check that:

  • Your token is correct (regenerate it from the dashboard if needed)
  • The server URL is correct
  • Your firewall isn't blocking the connection

The mod will automatically try to reconnect if the connection is lost.

▶ Can viewers modify my game or graph?

No. Viewers have read-only access. They can navigate, zoom, and search, but they cannot discover zones, add tags, or change anything.

Only you (the host) can modify the game state.

▶ How do I reset my progress / start a new run?

Create a new game from the launcher with your new randomizer seed. Each game is independent — your old games remain accessible from the dashboard.

▶ Does this work offline?

The web tracker has an offline mode where you can load a spoiler log locally. However, the in-game mod requires a server connection to sync discoveries.

If you just want to visualize a spoiler log without tracking, use the offline mode from the landing page.

Still have questions? Open an issue on GitHub
